# Dynamic Ride-Hailing Pricing in Chicago

## Team Members

- Kelsie McCall
- William Dang
- Patrick Phan

This project investigates how trip, demand, and weather factors affect ride-hailing fares in Chicago.

The analysis will use trip data from the City of Chicago's Transportation Network Providers dataset and weather data from NOAA's National Centers for Environmental Information.

---

## Project Overview

- **Objective:** Investigate how trip characteristics, demand, and weather conditions affect ride-hailing fares in Chicago.
- **Domain:** Transportation / Dynamic Pricing
- **Key Techniques:** Data cleaning, data integration, exploratory data analysis, visualization, statistical analysis, and predictive modeling.

### Research Question

**How do trip, demand, and weather factors affect ride-hailing fares in Chicago?**

## Data

### Chicago Ride-Hailing Data

- **Source:** City of Chicago Data Portal
- **Dataset:** Transportation Network Providers Trips
- **Source Link:** https://data.cityofchicago.org/
- **Description:** The dataset contains ride-hailing trip information such as trip start and end time, trip duration, distance, pickup and drop-off areas, fare, tips, and total trip cost.
- **License:** 

### NOAA Weather Data

- **Source:** NOAA National Centers for Environmental Information (NCEI)
- **Source Link:** https://www.ncei.noaa.gov/cdo-web/search
- **Description:** The weather dataset contains historical weather observations from NOAA weather stations in the Chicago area. Variables may include precipitation, temperature, snow, and other weather conditions.
